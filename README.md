# Personal Mini-Toolkit (PLP Python Week 8 Final Project)

## Description
The **Personal Mini-Toolkit** is a command-line Python application that brings together everything learned in the Power Learn Project Python course: variables, user input, conditionals (`if/elif/else`), loops (`while` loops), lists, and formatted strings (`f-strings`). 

The program runs in a continuous menu loop, allowing users to choose from three interactive tools or quit safely at any time with robust error handling for invalid inputs.

---

## Tools Included
1. **Number Guessing Game:** A game where the user tries to guess a secret number between 1 and 10 with interactive loop hints.
2. **Simple Calculator:** Performs basic arithmetic operations (+, -, *, /) on two numbers with division-by-zero protection.
3. **My Shopping List:** A dynamic list tool allowing users to view their current list items or add new items on the fly using Python lists.

---

## How to Run
1. Make sure you have [Python 3](https://www.python.org/) installed on your computer.
2. Download or clone this repository to your local machine.
